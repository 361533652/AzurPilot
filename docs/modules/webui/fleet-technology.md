# 舰队科技

入口为「舰队管理 → 舰船数据 → 舰队科技」，路由 `/i/:instance/task/FleetAnalysis?tab=technology`。旧科技路由自动跳转。

累计获取、满星、120 级里程碑是唯一正式统计依据，状态区分已完成、未完成、未核实。当前持有数量和最高等级独立展示；退役不会回退科技。完整图鉴中没有科技奖励的舰船仍可显示，但奖励列为空。

支持按未完成、未获取、缺满星、缺 120 级、未核实、当前持有、目标加成属性、舰种及阵营筛选。点击舰船或里程碑打开纠错面板，预览点数变化、查看来源及关联舰船。与当前已确认舰船事实矛盾的修改会明确报冲突，不能由隐藏的合并规则覆盖。

阵营科技等级单独维护，空值为未知，0 表示确认未升级。属性加成分别显示舰船科技、阵营科技及总加成；阵营表使用所选等级的累计值，避免重复相加。

静态奖励资料来自离线打包的 `assets/ship/fleet_tech.json`，名称与身份关联 `ship_data.json`，来源版本可在页面查看。满星推断依照舰船类型规则，不统一套用等级阈值。已知突破阶段优先于等级推断；只有突破未知时，才按普通舰船等级上限规则推断满星。当前突破修改不自动撤销历史科技，仍需通过纠正科技记录明确处理。

详细的数据流、存储、迁移和接口见 [舰船数据](fleet-analysis.md)，实施目标见 [重构计划](fleet-data-refactor-plan.md)。旧的底账/人工合并视图与低高等级切换已移除。
